# 업무포탈 운영 (2026-11-09부터)

- 주소: https://script.google.com/macros/s/AKfycbyATdbsyJxqsp2X_wlQO5L5TvyYsTqF9RCIU26u6R_OBdTXWbXfuCe42NzoTJICpI5_/exec
- 화면과 데이터를 Apps Script 웹앱 하나가 모두 제공한다(대표·실장 전용). GitHub Pages에는 포탈을 올리지 않고, 예전 주소(…github.io/…/portal/)는 위 주소로 자동 이동만 한다.

## 화면을 고칠 때
1. `sign/portal/index.html`(편집용 원본)을 고친다.
2. `python3 scripts/build_portal.py` → `sign/portal/portal.html` 생성(아이콘·사진 포함 한 파일).
3. 구글 드라이브 「업무포탈_AppsScript」 폴더에 portal.html을 새로 올리고 이전 것은 휴지통으로.
4. 사무실 크롬 Claude: 업무포탈 데이터 시트 > 확장 프로그램 > Apps Script > `portal` 파일 내용을 교체 → 저장 → 배포 > 배포 관리 > 연필 > 새 버전 > 배포. (새 배포 금지: 주소가 바뀜)

## 백엔드를 고칠 때
`sign/portal/Code.gs.txt`를 고쳐 같은 방식으로 Code.gs에 붙여넣고 새 버전 배포.
