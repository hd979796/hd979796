# 업무포탈 운영 (2026-11-09부터)

- 주소: https://script.google.com/macros/s/AKfycbyATdbsyJxqsp2X_wlQO5L5TvyYsTqF9RCIU26u6R_OBdTXWbXfuCe42NzoTJICpI5_/exec
- 화면과 데이터를 Apps Script 웹앱 하나가 모두 제공한다(대표·실장 전용). GitHub Pages에는 포탈을 올리지 않고, 예전 주소(…github.io/…/portal/)는 위 주소로 자동 이동만 한다.

## 화면을 고칠 때
1. `sign/portal/index.html`(편집용 원본)을 고친다.
2. `python3 scripts/build_portal.py` → `sign/portal/portal.html` 생성(아이콘·사진 포함 한 파일).
3. 구글 드라이브 「업무포탈_AppsScript」 폴더에 portal.html을 새로 올리고 이전 것은 휴지통으로.
4. 사무실 크롬 Claude: 업무포탈 데이터 시트 > 확장 프로그램 > Apps Script > `portal` 파일 내용을 교체 → 저장 → 배포 > 배포 관리 > 연필 > 새 버전 > 배포. (새 배포 금지: 주소가 바뀜)

## 백엔드를 고칠 때
`sign/portal/Code.gs.txt`를 고쳐 같은 방식으로 Code.gs에 붙여넣고 새 버전 배포.

## 같은 주소에서 여는 다른 페이지 (2026-11-09)
- 동의서 서명: `…/exec?page=sign` (Apps Script 파일 이름 `sign`, 내용 sign.html)
- 우당탕탕 요절복통: `…/exec?page=game` (파일 이름 `game`, 내용 game.html)
- 여보어디가TV 촬영장: `…/exec?page=studio` (파일 이름 `studio`, 내용 studio.html). 대표 업무 메뉴 「🎬 촬영장」. 기획·편집·일정은 claude.ai 제작실. 설치는 update7.md (2026-11-12)
- 설치: Apps Script 왼쪽 「파일 +」 > HTML로 `sign`, `game` 두 파일을 만들어 각각 붙여넣고, Code.gs도 최신 Code.gs.txt로 바꾼 뒤 새 버전 배포.
- GitHub Pages에서 내릴지는 대표님이 고른 뒤 정한다(남길 1~2개 제외하고 pages.yml에서 새 주소로 이동 처리).

## 주의: Apps Script 주석 제거 버그 (2026-11-10)
HtmlService는 내보낼 때 스크립트 주석을 지우는데, 줄 끝에 주석이 있으면 같은 줄의 "https://…"에서 //부터 잘라 문법 오류가 난다
(포탈이 로그인 화면도 안 뜨고 멈춤). `scripts/build_portal.py`가 스크립트 안의 `://`를 `:\/\/`로 바꿔 막는다. 반드시 이 스크립트로 만든 파일을 붙여넣을 것.
