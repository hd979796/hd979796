# 업무포탈 개편 2 (2026-11-08) — 자동차·일반보험 분리, 선물·우편 발송

## 바뀐 것
- 상단 탭을 업무 흐름대로 묶음: **자동차** (자동차 명단) · **일반** (일반보험 명단) · **발송** (선물·우편 발송) · **공통** (카드결제·요청함·고객·통화·멘트·공부방).
- 현황 화면 타일도 자동차 / 일반보험 / 발송 세 줄로 나눔. 일반보험 줄: 이달 만기 · 임박(10일 이내) · 만기 지남·미진행 · 갱신 완료. 발송 줄: 송장 대기(40만원 이상) · 라벨 대기(40만원 미만).
- **일반보험 명단** 신설. 기타전문인배상책임·하이기업종합플러스·승강기배상책임·생산물배상책임·화재 등. 같은 `cases` 탭에 `line:"일반"` 으로 저장되므로 백엔드(Apps Script) 수정 없음.
  - 필터: 전체(이달+임박+만기 지남) / 이달 만기 / 갱신 진행 / 임박 10일(안내 완료여도 포함) / 만기 지남·미진행 / 갱신 완료 / 미갱신. 상품별 칩.
  - 「만기리스트 붙여넣기」: 포탈 표를 붙여넣으면 만기일·계약자·상품·증권번호·작년 보험료를 찾아 올림. 같은 증권번호+만기일은 건너뜀.
  - 건 추가/상세: 계약자(업체명)·피보험자·상품(목록 선택)·목적물·전계약/갱신 증권번호.
- **선물·우편 발송** 신설 (자동차·일반 모두, 상태가 갱신완료인 건).
  - 40만원 이상 → 감사 선물: 「송장」(한 건), 「모두 출력」(대기 건 전부 한 번에, A4 한 장에 2건), 「선택 출력」, 「로젠 일괄등록 CSV」, 「로젠 접수」(기존 요청함 경로).
  - 40만원 미만 → 우편: 폼텍 3108(2×8) / 3107(2×7) / 3100(3×7) 라벨지에 주소 라벨 출력. 「시작 칸」으로 쓰다 남은 라벨지 사용.
  - 출력하면 송장 출력일(`waybillAt`) / 우편 발송일(`mailedAt`)을 자동 기록(끌 수 있음). 「명부에서 주소 채우기」는 보유고객 명부에서 같은 이름이 한 명일 때만 주소를 채움.
  - 「보내는 분 설정」: 상호·전화·주소·품목·배송 메시지 → `portal` 탭 `sender` 문서에 저장되어 모든 기기에서 공유.
- 자동차 명단: 「임박 10일」 필터 추가, 노란 줄 기준을 7일 → 10일로.
- 상세 창에 연락처(송장용)·우편번호·우편 발송일 칸 추가.

## 데이터
- `cases` 새 칸: `line`("일반"이면 일반보험, 비어 있으면 자동차), `insured`, `object`, `phone`, `zip`, `mailedAt`.
- `portal/sender`: 보내는 분 정보.
- 기존 데이터는 그대로 자동차로 보임. 백엔드 재배포 불필요.
