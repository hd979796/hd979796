    요청함 대기 Claude가 처리할 일

      명단에서 설계·안내·결제·증권출력·로젠 접수 버튼을 누르면 여기에 쌓이고, 실장님 PC의 Claude가 포탈과 로젠에서 처리한 뒤 완료로 바꿉니다.

          보상청구 기록

          접수일구분고객명내용처리

          사고접수 화면에서 배상책임 접수 메일을 보내거나 상해·질병 청구 PDF를 만들면 여기에 자동으로 남습니다(접수 완료 고객 확인용). 자동 기록 연결은 사고접수 스크립트에 한 번 설치해야 하며, 설치 전에는 「기록 직접 추가」로 남깁니다.

          차량배상책임 면적 계산 건축물대장 면적으로 배상책임 담보 면적 구하기

          휴대폰용 계산기 열기

          계산 과정

          1. ① 임대비율임대면적 ÷ 연면적-
          2. ② 공용면적대지면적 − 건축면적-
          3. ③ 공용 책임면적공용면적 × 임대비율-
          4. ④ 배상책임면적공용 책임면적 + 임대면적-
          차량배상책임 담보 면적- ㎡

          선물·우편 발송

          송장과 라벨의 보내는 분에 찍힙니다. 모든 기기에서 같이 씁니다.

          감사 선물 · 로젠택배 송장 보험료 40만원 이상 (장기는 월보험료×12 기준) · 상세에서 선물 대상/제외를 직접 정할 수도 있습니다

          완료일고객명구분연락처배송 주소보험료송장처리
          송장 전표는 A4 한 장에 2건씩. 「송장」은 한 건, 「모두 출력」은 대기 건 전부를 한 번에 인쇄합니다.

          우편 발송 · 주소 라벨 보험료 40만원 미만

          완료일고객명구분우편번호주소보험료라벨처리
          쓰다 남은 라벨지는 「시작 칸」에 이미 쓴 칸 수를 넣으면 그만큼 건너뜁니다.

          월 카드결제 (장기 계속보험료)

          카드결제명단 엑셀에서 성함~비고 칸을 드래그 복사해 붙여넣으세요(머리글 줄 포함 가능). 주민번호는 저장하지 않고 생년 6자리만 남깁니다. 붙여넣으면 기존 명단을 바꿉니다.

          고객생년명단 금액비고이번 달 결과계약 · 카드 · 승인

          「Claude에게 결제 요청」을 누르면 사무실 Claude가 카드결제 스킬대로 포탈에서 결제하고 결과를 여기에 남깁니다. 해지카드·승인거절은 빨간색으로 표시되니 고객에게 안내하세요. 직접 결제했으면 「기록」으로 남기면 됩니다.

          갱신 건 카드결제 자동차·일반 갱신 결제일별 · 카드번호는 적지 않습니다

          "결제 요청"을 누르면 Claude가 포탈에서 결제 화면까지 열고 금액을 맞춰 둡니다. 카드번호 입력과 결제 버튼은 실장님이 누릅니다. 결제가 끝나면 "결제 완료"를 눌러 증권발행으로 넘깁니다.

          요청함

            실장님 PC에서 Claude에게 "요청함 처리해"라고 하면 대기 건을 위에서부터 처리하고 결과를 남깁니다. 돈이 나가는 결제와 고객 발송은 Claude가 직전에 멈추고 확인을 받습니다.

            고객 검색

              보유고객 명부, 갱신·계약 명단, 고객 카드, 통화 기록을 한 번에 찾습니다. 전화번호는 숫자만 쳐도 됩니다.

              영업포탈 고객 조회 표(고객명 · 주민번호 · 휴대폰 · 주소 · 이메일 · 직업 …)를 드래그 복사해서 붙여넣으면 칸을 알아서 찾아 고객 카드에 넣습니다. 머리글 줄이 있으면 더 정확합니다.

              고객명주민번호휴대폰주소이메일직업·직장
              고객을 고르면 기본 정보, 가족관계, 진행 상황, 통화 기록이 여기에 나옵니다.

              통화 기록하기 저장하면 통화 기록에 남고 할 일 달력에도 바로 등록됩니다

                    오늘 보낼 안내

                      새 장기계약 등록 청약일 + 면책기간 → 보장 개시일 자동 계산

                      단체 인사 보내기 명절·계절 · 내 휴대폰 문자로 무료

                      보내기 전에 확인
                      • 한 명씩 보내기: 이름이 들어간 문자가 열리면 전송 → 다시 이 화면으로 돌아오면 다음 사람이 바로 준비됩니다.
                      • 20명씩 묶어 보내기: 이름 없이 같은 문구가 갑니다. 삼성 메시지 설정 → 추가 설정 → 멀티미디어 메시지 → 그룹 대화 끄기를 해야 각자 따로 받습니다.
                      • 밤 9시~아침 8시에는 보내지 마세요. 상품 홍보가 들어가면 맨 앞에 (광고)를 붙여야 합니다. 인사만 하는 문자는 괜찮습니다.
                      • 통신사가 하루에 보낼 수 있는 문자 수를 제한합니다. 많으면 이틀에 나눠 보내세요.

                      장기계약 고객

                        수술검색 퍼펙트플러스(Hi2610) [별표92-1] 1-5종수술Ⅳ 분류표 전체

                        질병 분류 검색 24대 · 58대Ⅱ · 5대기관 · 다발성10대 — 퍼펙트플러스(Hi2610) [별표54~57]

                        진단서의 질병코드(KCD)로 판정합니다. 진단 확정 당시의 한국표준질병사인분류 기준이며, 분류번호가 동시에 부여된 경우(동시 진단 코드)도 포함합니다.

                        꼭 같이 보는 규칙 분류표 주석 · 사용 지침(1368쪽)

                        • 수술할 때마다 지급합니다. 같은 질병으로 동시에 두 수술을 받으면 가장 높은 종 하나만 지급합니다. 부위가 다르고 치료 목적이 다른 독립 수술이면 각각 지급합니다.
                        • 내시경·카테터 수술은 1~87항이 아니라 88항(뇌·심장 3종 / 흉부·복부장기·척추·사지관절 2종 / 비뇨·생식기·손발가락 1종)을 적용합니다. 단 복강경·흉강경은 해당 부위(1~87항) 수술로 봅니다.
                        • 60일 안에 반복한 수술은 1회로 봅니다: 내시경·카테터(88항), 맘모톰, 경질적 자궁·난소 수술, 망막박리, 레이저·냉동응고 안구수술, 중이 튜브, 체외충격파쇄석술, 암 내시경·기타 암수술, 근치 방사선.
                        • '관혈'은 피부를 절개해서 병변을 직접 보며 하는 수술, '근본·근치'는 한 번에 병을 완전히 낫게 하는 수술입니다. 분류표에 없는 신의료기술(신의료기술평가위원회 인정)은 같은 부위 수술로 봅니다.
                        • 보상 제외: 흡인, 천자(바늘로 뽑기·주입), 신경차단, 미용성형, 피임, 피임·불임술 후 가임 목적 수술, 검사·진단 목적 수술(생검, 복강경 검사 등).
                        • 제자리암·경계성종양 수술은 일반 수술 항목(Ⅰ)을 적용합니다. 상해 수술은 상해수술Ⅲ(1-5종) [별표36]을 따로 확인하세요.
