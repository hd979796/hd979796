# 업무포탈 개편 3 (2026-11-08) — 장기 / 자동차 / 일반 대분류, 보상·청구 연결

## 구조
- 상단 탭: **현황 · 장기 · 자동차 · 일반 · 보상·청구 · 발송 · 고객** (굵게) + 요청함 · 카드결제 · 통화·할 일 · 멘트 · 공부방 (작게).
- **기준월**이 하나로 통일됨(현황·각 줄 화면의 선택이 같이 움직임). 줄 화면의 「전달」「이달」 버튼으로 바로 바꿈.
- 세 줄(장기·자동차·일반)이 같은 틀을 씀:
  1. 타일 4개 — 그 달의 신규/진행/완료/미완료
  2. 업무 대기 칩 — 임박 10일 · 만기 지남 · 증권출력 대기 · 송장 대기 · 우편 대기 · 카드결제 대기 (누르면 그 명단으로 필터)
  3. 명단 — 상태는 표에서 바로 변경, 「증권」 칸에서 증권출력 요청, 「발송」 칸에서 송장·라벨 바로 출력, 「처리」에서 설계·안내·카드 요청
  4. 붙여넣기 — 장기는 계약 목록, 자동차·일반은 만기리스트
- 현황: 줄마다 한 카드(업무 대기 칩 + 숫자 4개, 누르면 해당 명단), 이번 주 만기, 요청함 대기, 보상·청구 바로가기, 할 일, 최근 통화, 하이포탈 실적.

## 장기보험 (신설)
- `cases` 탭에 `line:"장기"`. 날짜 칸(`due`)은 **청약·계약일**로 쓰고 그 달로 묶음.
- 상태: 상담 → 설계완료 → 청약완료 → 심사중 → **계약완료** / 철회·거절 / 보류. 구분: 신규·추가계약·리모델링·갱신.
- `premium` = 월 보험료. 선물 기준은 월보험료×12 ≥ 40만원(상세의 「감사 선물」에서 대상/제외로 직접 지정 가능 — 세 줄 공통).
- 계약완료가 되면 증권출력 대기·송장(또는 우편) 대기에 자동으로 올라감.

## 보상·청구 (신설)
- 바로가기: 보험청구방(상해·질병 청구 접수·대장) · 배상책임 사고접수방 · 보험금 검산방 · 동의서 서명 · 하이 영업포탈.
- 고객에게 보낼 링크 복사: 상해·질병 청구서 작성(보험사 선택 가능), 배상책임 사고접수 — 기존 방들과 같은 문구·링크.
- 청구 요청 올리기 → `requests`에 kind 상해질병청구 / 배상책임청구 / 보험금검산 / 자동차사고접수. 진행 목록은 같은 화면에서 완료 처리.

## 데이터
