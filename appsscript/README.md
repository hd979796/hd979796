# 개인정보처리 동의서 서명 (구글 앱스크립트)

휴대폰에서 동의서 PDF를 열어 동의함 전체 체크, 고객 서명, 오늘 날짜 자동 기입을 하고
서명된 PDF를 대표님 구글 드라이브 "개인정보동의서" 폴더에 저장, 기록 시트에 남기고, 메일로 보냅니다.

## 배포 (사고접수 시스템과 같은 방법)
1. https://script.google.com 에서 새 프로젝트 만들기, 이름: 동의서 서명
2. Code.gs 내용을 기본 Code.gs에 붙여넣기
3. 왼쪽 + > HTML > 이름 `Index` 로 만들고 Index.html 내용 붙여넣기
4. 배포 > 새 배포 > 유형: 웹 앱 > 실행: 나 / 액세스 권한: 모든 사용자 > 배포
5. 권한 승인 (드라이브, 시트, 메일) 후 나오는 웹 앱 URL(…/exec)을 사용

## 설정 (Code.gs 맨 위)
- FOLDER_NAME: 저장 폴더 이름
- FAX_EMAIL: 이메일로 팩스를 보내주는 서비스 주소가 있으면 입력하면 팩스까지 자동 발송
- PIN: 아무나 저장하지 못하게 할 비밀번호 (선택)
