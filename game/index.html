🎲 랜덤 리그 대진표

모두 한 번씩 붙는 리그(4명이면 각자 3경기)를 무작위로 만듭니다. 사람이 많으면 코트를 2개로 나누고, 1인당 경기 수를 줄일 수 있습니다. 점수를 넣으면 진 사람에게 비용이 자동으로 붙습니다. 리그가 끝나면 1등은 3,000원을 빼고 꼴등은 3,000원을 더합니다(꼴등이 1등에게 주는 셈). 사람이 많으면 1등·꼴등을 2명씩 정할 수 있습니다.

⚙️ 멤버설정

이름과 급수를 넣고 자석을 만들어 두세요. 여러 명은 띄어쓰기로 구분합니다.

📖 게임룰

🙋 참석

  • 멤버설정에서 이름과 급수로 자석을 만들어 둡니다.
  • 급수 색: S조 황금 · A조 빨강 · B조 주황 · C조 녹색 · D조 흰색
  • 자석을 누르면 오늘 참석 명단에 들어갑니다.

✏️ 바를 정(正) 표시 — 짝대기 1개 = 1,000원

  • 7시 전 한 게임 지면 2,000원 → 파란 짝대기 2개
  • 7시부터 한 게임 지면 3,000원 → 빨간 짝대기 3개
  • 더블패(두 배 점수 차): 21점 게임에서 10점 미만, 25점 게임에서 13점 미만으로 지면 +1,000원 → 빨간 짝대기 1개 추가
  • 듀스패: 듀스(21점 게임 20:20, 25점 게임 24:24)까지 가서 지면 +1,000원 → 빨간 짝대기 1개 추가
  • 正 한 글자 = 5,000원

🎲 랜덤 리그

  • 참석자끼리 모두 한 번씩 붙도록 무작위로 대진표를 만듭니다. 사람이 많으면 코트를 2개로 나눕니다.
  • 리그에서 지면 3,000원(빨간 짝대기 3개), 더블패·듀스패는 +1,000원.
  • 순위: 득실차가 큰 사람이 위. 득실이 같으면 승자승(맞대결)으로 정합니다.
  • 리그가 끝나면 1등 −3,000원, 꼴등 +3,000원 (꼴등이 1등에게 주는 셈). 사람이 많으면 1등·꼴등 2명씩.
