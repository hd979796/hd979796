# 우당탕탕 요절복통 — 서버(구글 시트) 설치 안내

회원 45명이 같은 현황판을 보려면 기록을 저장할 곳이 필요합니다. 여기서는 **구글 시트**를 저장소로 씁니다. 무료이고 10분 정도 걸립니다.

설치 전에는 웹페이지가 **체험 모드**로 열립니다. 체험 모드의 기록은 그 휴대폰에만 저장됩니다.

## 1. 구글 시트 만들기
1. 구글 드라이브에서 **새 스프레드시트**를 만들고 이름을 `우당탕탕 명부`로 바꿉니다.
2. 이 시트는 **아무에게도 공유하지 마세요.** 회원 전화번호·생년월일·주소가 들어갑니다.

## 2. 서버 코드 붙여넣기
1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
2. `Code.gs`에 있던 내용을 모두 지우고, 이 폴더의 **`Code.gs.txt` 내용 전체**를 붙여넣습니다.
3. 💾 저장합니다.

미리 정해 둔 직책은 다음과 같습니다. 코드 맨 아래쪽 `PRESETS`에서 바꿀 수 있습니다.

| 이름 | 직책 |
|---|---|
| 도민구 | 회장 |
| 지승욱 | 총무 |
| 박문철 | 관리자 |

이 이름으로 가입하면 직책이 자동으로 붙고, 나머지는 '일반'입니다. 가입 후에는 웹페이지의 🛡️ 운영 메뉴에서 임명합니다.

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴에서 유형 **웹 앱**을 고릅니다.
3. 설정을 이렇게 맞춥니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
4. **배포**를 누르고 권한을 승인합니다.
   - "확인되지 않은 앱" 화면이 나오면 **고급 → (안전하지 않음)으로 이동**을 누릅니다. 본인이 만든 코드라 괜찮습니다.
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해서 Claude에게 알려 주세요.
   - 웹페이지(`index.html`)의 `API_URL`에 넣어 배포하면 실제 서버 모드로 바뀝니다.

## 4. 시트에 생기는 탭

| 탭 | 내용 |
|---|---|
| members | **멤버 명부**: 이름, 전화번호, 생년월일, 주소, 급수, 직책, 가입일 |
| days | 날짜별 현황판(자석·짝대기·리그) |
| payments | 입금 기록(미입금 / 입금했어요 / 확인완료) |
| notices | 공지·승급 소식 |
| settings | 총무 계좌 |

비밀번호는 원래 글자가 아니라 암호화한 값만 저장됩니다.

## 서버 코드를 고친 뒤
`server.js`나 `gas-adapter.js`를 고치면 `./build-gs.sh`로 `Code.gs.txt`를 다시 만듭니다. 그다음 Apps Script에 붙여넣고 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 누릅니다. 이렇게 하면 웹앱 URL이 바뀌지 않습니다.
