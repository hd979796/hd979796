# 우당탕탕 요절복통 — 서버(구글 시트) 설치 안내

회원 45명이 같은 현황판을 보려면 기록을 저장할 곳이 필요합니다. 여기서는 **구글 시트**를 저장소로 씁니다. 무료이고 10분 정도 걸립니다.

설치 전에는 웹페이지가 **체험 모드**로 열립니다. 체험 모드의 기록은 그 휴대폰에만 저장됩니다.

## 1. 구글 시트 (이미 만들어 둠)
- 시트: [우당탕탕 명부 (서버 저장소)](https://docs.google.com/spreadsheets/d/18BouDAq7u4MmJEDXXWdTc6wR6icXR-p03eUoeeDq33g/edit)
- 서버 코드는 이 시트 주소(`SHEET_ID`)로 연결돼 있습니다.
- 이 시트는 **아무에게도 공유하지 마세요.** 회원 전화번호·생년월일·주소가 들어갑니다.

## 2. 서버 코드 붙여넣기 (PC 권장)
1. 위 시트를 열고 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
2. `Code.gs`에 있던 내용을 모두 지우고, 서버 코드 전체를 붙여넣습니다.
   - 서버 코드: 드라이브의 [우당탕탕 서버코드 v3 (Apps Script에 붙여넣기).txt](https://drive.google.com/file/d/1NHwzyCmbc4EKCX2kvYUPlMdVjqmsH9W9/view) 또는 이 폴더의 `Code.gs.txt`
3. 💾 저장합니다.

**직책과 관리자** (회칙 제6·8조)
- 가입하면 모두 '일반'으로 시작합니다. 정원은 50명입니다.
- 집행부(회장·부회장·총무, 각 1명), 임원진(4명, 직위 이름은 직접 입력), 인턴은 회장이나 관리자가 웹페이지 🛡️ 운영 → 🎖️ 직책·급수에서 정합니다. 회장은 관리자만 바꿀 수 있습니다.
- **관리자**는 화면에 표시되지 않고 권한만 있습니다. 직책 정하기, 관리 권한 주기, 비밀번호 초기화, 탈퇴 처리를 할 수 있습니다.
- 서버 코드 아래쪽 `ADMINS = ['박문철']`에 적힌 이름은 늘 관리자입니다.
- 지각 기준의 '강북권·의정부' 지역은 `server.js`의 `NEAR_RE`(의정부·강북구·도봉구·노원구)로 정합니다.

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴에서 유형 **웹 앱**을 고릅니다.
3. 설정을 이렇게 맞춥니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
4. **배포**를 누르고 권한을 승인합니다.
   - "확인되지 않은 앱" 화면이 나오면 **고급 → (안전하지 않음)으로 이동**을 누릅니다. 본인이 만든 코드라 괜찮습니다.
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해서 Claude에게 알려 주세요.
   - 웹페이지(`index.html`)의 `API_URL`에 넣어 배포하면 실제 서버 모드로 바뀝니다.

## 4. 시트에 생기는 탭

| 탭 | 내용 |
|---|---|
| members | **멤버 명부**: 이름, 전화번호, 생년월일, 주소, 급수, 직책, 가입일 |
| days | 날짜별 현황판(자석·짝대기·리그) |
| payments | 입금 기록(미입금 / 입금했어요 / 확인완료) |
| notices | 공지·승급 소식 |
| settings | 총무 계좌 |

비밀번호는 원래 글자가 아니라 암호화한 값만 저장됩니다.

## 서버 코드를 고친 뒤
`server.js`나 `gas-adapter.js`를 고치면 `./build-gs.sh`로 `Code.gs.txt`를 다시 만듭니다. 그다음 Apps Script에 붙여넣고 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 누릅니다. 이렇게 하면 웹앱 URL이 바뀌지 않습니다.
